# TypeScript 
A hands-on practice repository for rebuilding TypeScript confidence and preparing for senior
frontend interviews. The repo starts with a small, strict TypeScript project and provides a
place to organize exercises, examples, and interview notes.

## Goals
- Revisit TypeScript fundamentals with small runnable examples.
- Practice explaining trade-offs and design decisions out loud.
- Keep coding exercises separate from interview notes.
- Later connect TypeScript concepts to Angular, RxJS, NgRx, and AI integration.

## Prerequisites

- Windows, macOS, or Linux
- Node.js LTS and npm
- Git
- VS Code

Check your installation:
node --version
npm --version
git --version


## Setup
- Move into the project folder first.
- cd project_folder

- Install the project-local TypeScript compiler.
- npm install

- Type-check without generating output.
- npm run check

- Compile TypeScript into dist/.
- npm run build

- Run the compiled example.
- npm start

- To run individual files:
-- npm install -D tsx 
-- npm rebuild esbuild
-- npm install
-- npx tsx index.ts


For each topic:
1. Read the concept.
2. Write a tiny example without copying.
3. Add at least two edge cases.
4. Run `npm run check`.
5. Explain the code aloud as if answering an interviewer.
